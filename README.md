# Сфера 360

Съёмка сферической панорамы 360°×180° обычным телефоном — прямо в браузере, без 360-камеры и без сервера.

**Открыть:** https://egordikanskiy.github.io/sfera360/ (с телефона, в Safari или Chrome).

## Что умеет

- **Съёмка по точкам.** Цели на сфере строятся по гироскопу, кадр снимается сам, когда телефон наведён и неподвижен.
- **Склейка в браузере:**
  - опорные точки и сопоставление по пирамиде с поправкой дрейфа гироскопа;
  - связка всех кадров (bundle adjustment по лучам) с подбором фокусного расстояния;
  - **параллакс:** если телефон двигался по дуге вокруг тела (съёмка с рук), отдельная связка оценивает центры кадров и обратную глубину точек, плотная глубина ищется вдоль эпиполярных линий, а сфера собирается с учётом глубины сцены;
  - выравнивание экспозиции (лог-усиления по каналам);
  - **швы в обход предметов и прохожих:** graph cut (α-расширение, максимальный поток) с «согласием с медианой», которое убирает людей, прошедших между кадрами;
  - двухполосное смешивание: низкие частоты плавно, детали — по шву.
- **ИИ-дорисовка (MI-GAN, ONNX Runtime Web, работает на телефоне):**
  - пустоты, куда не попал ни один кадр, нейросеть заполняет автоматически; у больших пустот (потолок и пол у панорамы с телефона) продолжает только край на ~15°, дальше идёт плавная заливка — так сеть не выдумывает предметы;
  - **ИИ-кисть** в просмотре: закрашиваете место с искажением (двоение, разрыв, человек), и нейросеть перерисовывает его. Изменения можно отменить;
  - всё дорисованное помечено: «Дорисованное» показывает штриховку (фиолетовая — нейросеть, оранжевая — заливка цветом).
- **Панорама из галереи:** обычный снимок в режиме «Панорама» ставится на сферу по метаданным GPano или по найденному замыканию круга.
- **Экспорт:** equirectangular JPEG 2:1 с метаданными GPano (до 8192×4096, на iPhone до 5760×2880), табличка на надире.

## Устройство

| Путь | Что это |
|---|---|
| `index.html` | собранное приложение (один файл) |
| `src/core.js` | ядро: геометрия, сопоставление, связки, глубина, швы, сшивка, ИИ-дорисовка, демо-зал |
| `src/app.html` | интерфейс: съёмка, обработка, просмотр WebGL, ИИ-кисть, экспорт |
| `build.py` | сборка `src/*` → `index.html` |
| `models/migan_pipeline_v2.onnx` | MI-GAN 512 (Places2), конвейер ONNX |
| `vendor/ort/` | ONNX Runtime Web 1.24.3 (WASM) |
| `tests/` | стенды на синтетическом зале: точность поз, параллакс, прохожий, ИИ-дорисовка |

Сборка: `python3 build.py`. Тесты (Node 22): `node tests/bench.js` (переменные `HH=0.3 PERSON=1` — съёмка с рук и прохожий), `node tests/aibench.mjs demo|pano`.
