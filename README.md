# Сфера 360

Съёмка сферической панорамы 360° обычным телефоном: точки-цели по гироскопу, автоспуск, склейка прямо в браузере (сопоставление с поправкой дрейфа гироскопа, связка кадров с подбором фокуса, выравнивание экспозиции, двухполосное смешивание), просмотр 360° и экспорт equirectangular JPEG с метаданными GPano.

Открывать с телефона по https (GitHub Pages): камера и датчики движения в браузере работают только в защищённом контексте.
