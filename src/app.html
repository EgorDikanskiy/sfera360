Камера работает только по HTTPS.Опубликуйте файл на GitHub Pages, Netlify или Vercel и откройте ссылку с телефона. Демо-зал и панорама из файла работают и так.

«Панорама из галереи» превращает обычный снимок в режиме «Панорама» в сферу: полосу ставит на место, края потолка и пола продолжает нейросетью. «Демо-зал» показывает всю склейку на имитации съёмки с рук — подходит для компьютера.

Как снимать

  • Вращайте телефон вокруг объективаНе вокруг себя. Объектив почти не сдвигается, двигается только направление. Иначе близкие витрины «поплывут» на швах.
  • Наведите кружок на точку и замритеКадр снимется сам за полсекунды. Отметки остаются на своих местах в пространстве.
  • Пройдите все ряды, потом потолок и полСредний ряд, верхний, нижний, затем зенит и надир. В кадре надира будут ваши ноги — это нормально, его можно закрыть табличкой.
  • Снимайте, когда в зале нет людейЧеловек, который прошёл между кадрами, может раздвоиться на шве.

«Авто» подбирает ширину по фокусному расстоянию камеры, чтобы не растягивать пиксели.
Склейка и нейросеть работают прямо в браузере, фотографии никуда не отправляются. Порядок: опорные точки → совмещение с поправкой дрейфа гироскопа → связка кадров с подбором фокуса → если телефон двигался, связка с параллаксом и глубина сцены → выравнивание экспозиции → швы в обход предметов (graph cut) → двухполосное смешивание → ИИ-дорисовка пустот → equirectangular 2:1 с метаданными GPano.
